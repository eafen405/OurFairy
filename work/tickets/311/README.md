# 让印象帮助 Fairy 理解用户，保持对话连续

发布票：[GitHub #311](https://github.com/eafen405/OurFairy/issues/311)。2026-11-09 按用户确认的需求精简；本票仍待整合与验证。

## 核心诉求

用户希望 Fairy 记得对自己的认识，让相处越来越连贯；这些印象应帮助她理解用户，同时保持她自己的性格与身份。

## 要做的事

将印象作为当前用户的参考资料承载，复用已有资料通道和压缩保护。独立分支已有工程候选，待整合到当前版本。

## 完成时应看到

- 印象更新后，Fairy 能在后续交流中自然使用；本人归属、资料装配及压缩恢复有工程证据，当前问题和工具记录能够接续。
- 通过包含正常印象的完整对话，观察理解与连续性是否改善。人格表现交由 #314 的语境评价，不以拒绝措辞或投毒零失败作为本票完成条件。

历史实现与验证见[工程候选记录](https://github.com/eafen405/OurFairy/blob/20667e063667c6ae6fd6553c6b6b5c87aa380ec6/work/implementation/evidence/311-impression-channel/README.md)。
