## What to build

交付一个记忆插件，使 Fairy 能通过一小组工具新增、查询、编辑、删除和切换长期记忆；普通与私密共用接口，来源、日期和门禁行为符合规格。

## Acceptance criteria

- [ ] 新增只需内容和可选 is_private，默认普通；来源会话与归属用户由系统注入。
- [ ] 关键词与可选成对闭区间日期检索返回编号、内容、归属用户和内容更新时间，省略日期搜索全部，缺边或非法边界报错。
- [ ] 普通与深层检索互斥，查询按字面关键词匹配，不引入向量或语义扩展。
- [ ] 编辑按编号和旧新文本唯一匹配，删除物理执行，switch 双向切换且不产生副本。
- [ ] 编辑、删除和切换只允许当前会话已查询到的编号，新增后必须先查询才能变更。
- [ ] 新增与内容编辑更新来源和内容更新时间，查询与 switch 不改变内容更新时间。
- [ ] 整数编号删除后不复用，检索条数和字符预算及截断信息明确。
- [ ] 记忆插件使用独立 SQLite、版本化迁移和事务，真实产品会话工具测试通过。
