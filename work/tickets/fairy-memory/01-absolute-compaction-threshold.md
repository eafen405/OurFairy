## What to build

让 dsh 原生压缩能够接受可选的绝对 token 阈值，并与模型容量共同决定实际触发点。配置在后续压缩判断中生效，未配置时保持既有行为。

## Acceptance criteria

- [ ] 绝对阈值、路由比例阈值和容量余量共同取最小值，未配置绝对阈值时原有解析结果不变。
- [ ] 绝对阈值支持运行期读取，后续压力判断采用新值，不停留在构造期快照。
- [ ] 配置校验拒绝非法数值，较小模型窗口仍能压低实际触发点。
- [ ] 配置解析、真实 Loader、生成文档和相关 dsh 门禁通过。
