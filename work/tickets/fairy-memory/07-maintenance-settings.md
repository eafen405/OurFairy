## What to build

法厄同能调整维护触发回合数和维护门槛衰减间隔，复用自动压缩设置中的滑块与直接输入组件，并让新值在后续维护判断中生效。

## Acceptance criteria

- [ ] 设置按“记忆 → 维护”归属呈现，不与模型或自动压缩配置平铺。
- [ ] 维护触发回合数默认 15、范围 5–50，维护门槛衰减间隔默认 6 小时、范围 3–24 小时。
- [ ] 两项复用同一数值组合控件和草稿、校验、错误反馈逻辑。
- [ ] 非法输入在客户端和服务端均被拒绝，普通代理人不能修改。
- [ ] 保存后下一次维护评估采用新值且不重置既有水位，重启后保留。
- [ ] 修改衰减间隔或初始回合数后，搁置区间按新配置重新计算触发条件。
