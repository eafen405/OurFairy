## What to build

法厄同能在独立的上下文设置中通过滑块或直接输入调整自动压缩触发阈值，保存后热生效并跨重启保留，且与模型配置完全分离。

## Acceptance criteria

- [ ] 设置按“上下文 → 自动压缩 → 自动压缩触发阈值”呈现，不出现在模型配置中。
- [ ] 默认值 500K，范围 100K–900K，界面以 K token 显示并保存完整整数。
- [ ] 滑块与直接输入编辑同一草稿，非法输入在客户端和服务端均被拒绝且不静默截断。
- [ ] 可复用数值组合控件包含单位、范围校验、忙态和错误反馈。
- [ ] 保存后下一次压力判断使用新值，重启后保留，模型切换不改变该设置。
- [ ] 普通代理人不能读取或修改这项部署级设置。
