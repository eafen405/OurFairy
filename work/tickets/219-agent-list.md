# #219 代理人互见：客户端用户名列表（最小暴露面）

来源：GitHub issue #219，2026-10-25 读取；blocked-by 为 0。GitHub 票面为发布权威。

## 目标

任何登录用户都能在客户端看到其他代理人的存在，界面只显示用户名。为此提供最小的只读暴露面——
仅用户编号与用户名，不泄露任何其他信息；当前没有用户枚举接口，需要新增这一最小接口支撑前端显示。

## 交付与验收

- 登录用户可在客户端看到其他代理人的用户名（含自己）。
- 暴露面仅限存在性：用户编号与用户名，不含其他资料。
- 未登录或凭据无效拿不到列表。
- 行为有后端测试覆盖。
- Fairy 侧工具与“印象”不在本票范围。

## 范围与边界

- 新增的枚举接口只返回用户编号与用户名；不返回权限、创建时间、邀请、凭据或其他资料。
- 不改会话归属、消息、投递、分组与身份认证语义。
- 不新增 Fairy 工具、不新增“印象”数据。

## 测试约定

- 后端：经仓库既有启动器驱动真实后端，断言未登录/无效凭据拒绝、登录后列表只含编号与用户名、包含自己。
- 客户端：沿用现有 Robolectric／Compose 页面测试边界；测可见行为，不测私有组件结构。
