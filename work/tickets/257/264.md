## What to build

把登录、注册、会话、会话列表及通知定位等剩余目的地迁到生产 catalog，删除平行的身份与恢复映射。所有页面和测试使用同一份拓扑定义，新增目的地遗漏任一策略时会被完整性测试立即发现。

## Acceptance criteria

- [ ] 所有目的地都由生产 catalog 提供页面装配、身份准入和显式恢复策略，不再有平行映射表。
- [ ] 登录与注册只向未登录用户开放，且不会作为已登录后的冷启动恢复位置。
- [ ] 会话恢复保留会话编号；缺失、过期或无权目标继续按既有规则处理。
- [ ] 通知定位继续校验端点、用户编号与会话坐标，不绕过身份准入。
- [ ] 会话列表目的地在本票仍保留并显式恢复，删除工作留给后续会话导航票。
- [ ] 页面测试不再维护手抄路由或测试专用导航实现，表驱动测试枚举全部目的地及三种身份。
- [ ] 新增目的地缺少页面、准入或恢复策略时，完整性测试会失败。
- [ ] 相关 Android 测试、lint 与构建通过，生产路由和测试路由来自同一权威。
