## What to build

建立静态目的地 catalog 的第一条完整路径：首页、设置、网关和印象页从同一处获得页面装配、身份准入与冷启动恢复策略。印象页可以按明确返回栈恢复，其余旧映射暂时共存以保持全量行为绿色。

## Acceptance criteria

- [ ] 静态 catalog 同时驱动首页、设置、网关和印象页的页面装配、身份准入与恢复，不引入动态注册或插件发现。
- [ ] 未登录、普通代理人和法厄同分别得到正确的准入结果，网关仍只向管理员开放。
- [ ] 首页、设置与网关保持既有恢复栈；印象页明确恢复为首页、设置、印象。
- [ ] 每个已迁移目的地都显式声明恢复策略，不通过未处理的兜底分支静默决定。
- [ ] 未迁移目的地继续通过旧路径工作，登录、会话、通知与页面行为不回归。
- [ ] catalog interface 的表驱动测试覆盖已迁移目的地，Activity 层至少验证一条生产冷启动恢复路径。
- [ ] 不修改页面内容、返回语义、后端权限或通知记账。

## Blocked by

None (can start immediately).
