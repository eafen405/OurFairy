# 记忆操作准确，避免重复保存操作说明

发布票：[GitHub #313](https://github.com/eafen405/OurFairy/issues/313)。2026-11-09 按用户确认的需求精简；仍待修复与验证。

## 核心诉求

用户希望 Fairy 准确记住有价值的事实与偏好，调整一条记忆时就把这件事做好，不把操作说明反复存成额外记忆。

## 要解决的问题

已有真实样本中，原记忆成功切换到私密层后，模型又调用 `memory_add` 保存了一条引用规则。需要厘清长期事实与本次记忆操作的区别，复用现有工具和存储语义处理。

## 完成时应看到

- 新增、查询、切层及重复请求符合用户意图；切层保留原条目，重复操作不累积说明或正文副本，真正值得记住的事实与偏好仍能保存。
- 根据实际工具调用和完整最终存储行确认结果，保留真实对话与失败记录。
- 保持 #240 的共享记忆语义：普通检索不包含私密层，显式私密检索仍可使用共享私密记忆，不承诺用户独占。

历史样本与结果见[验收记录](https://github.com/eafen405/OurFairy/blob/main/work/implementation/evidence/302-249-integration/README.md)。
