## What to build

一次测量就能回答"最新快照是否已经应用并呈现"，而不只是报告跳过了多少份。结果包含已接收/已观察/被跳过版本、最终是否有版本未应用、终态格式呈现延迟、以及接收合并、排序、行重建、解析、布局绘制、滚动请求各阶段的耗时；采集脚本同时记录设备与构建条件。

## Acceptance criteria

- [ ] 结果明确报告最新版本是否已应用并呈现；无法判定时报错而不是写 0
- [ ] 分阶段指标足以把热点定位到具体阶段
- [ ] 脚本采集设备型号、系统版本、刷新率、字体与字号、构建类型、构建 SHA、签名类型与负载参数
- [ ] 清除启动帧后再进入工作负载窗口
