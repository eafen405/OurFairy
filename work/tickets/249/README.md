## 目标
- 印象对用户只读，Fairy 保留用户明确要求时的先读后改工具路径。
- 以游戏台词证据形成适度体量人格，经真实模型语义验收后替换部署人格。
- 不增加运行时人格输出审查或超大台词上下文。

## 验收
- 后端与 Android 均不存在用户印象写入口，Fairy 工具归属、先读后改、长度限制与隔离保持有效。
- 日常表达、详细解释、形式配合和注入场景完成真实模型语义验收，候选通过后更新部署人格。
- 同步 fairy-memory 与 ourfairy-v1 规格、相关测试和证据。
- 最终通过 npm test、combo:verify 与 Android test/lint/assembleDebug。
