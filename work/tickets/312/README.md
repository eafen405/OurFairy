# 让 Fairy 自然稳定地交流，并把事情办好

发布票：[GitHub #312](https://github.com/eafen405/OurFairy/issues/312)。2026-11-09 按用户确认的需求精简；仍待真实体验验证。

## 核心诉求

用户希望日常聊天、受托办事和连续相处时，面对的是同一个有性格的 Fairy：自信、得意、体贴，带一点冷面幽默和小情绪；她能理解当下需要，也能把事情办好。

## 要做的事

以已确认的人格文本和六条语感引文为基线，用真实对话评估需要改善之处。联网用于补足任务所需信息，已有依据够用时及时回答，缺少材料时说清缺口。复用现有工具与执行能力。

## 完成时应看到

- 闲聊、支持、纠错和办事中的表达自然贴切，多轮对话仍有连续的性格与关系分寸；结合语境评价潜台词和表达效果，不按固定口癖或拒绝词打分。
- 用户得到符合委托的结果，或明确的缺项说明；联网任务可核对实际来源与完成情况，记录耗时和用量。
- 候选改动与当前稿在可比条件下观察，保留完整对话及未改善的问题。原路线问题作为历史案例，不让单题通过代替整体体验。

人格评价方法见 #314；历史实现、语料与结果见[实施记录](https://github.com/eafen405/OurFairy/blob/main/work/implementation/evidence/312-network-persona/README.md)。
