## What to build

控制台“全部会话”和无可用会话时的主按钮直接打开共享会话列表浮层，不再先进入错误底页。控制台同时显示与列表、标题栏一致的当前会话标题，让用户清楚知道自己将进入哪个会话。

## Acceptance criteria

- [ ] 控制台两个会话列表入口都直接打开共享浮层，不经过会话编号为空的对话页。
- [ ] 对话页与控制台使用同一列表 module 和相同的选择、关闭行为，浮层不进入导航返回栈。
- [ ] 控制台显示当前会话标题；无标题时使用与列表一致的占位名称，不显示 opaque id。
- [ ] 当前会话编号与标题来自同一份远程会话快照，不建立本地标题副本或重新推断标题。
- [ ] 长标题、窄屏和大字体下主要操作仍可达，标题合理截断。
- [ ] 旧会话列表目的地暂时保留兼容，现有通知和冷启动行为不回归。
- [ ] 页面测试覆盖两个入口、标题一致性、关闭浮层和选择会话，不使用测试专用路由。
