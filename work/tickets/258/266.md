## What to build

共享会话列表浮层完整承担现有会话管理能力，归档当前会话后的跟随规则由会话状态 module 统一拥有。用户归档后进入主会话，过期或无权目标仍明确不可用，页面不再自行猜测列表变化的原因。

## Acceptance criteria

- [ ] 默认会话、归档视图、恢复、改名、停止回复以及首页和设置入口在共享浮层完整可用。
- [ ] 归档当前会话后，会话状态驱动跟随主会话，页面不再维护“曾经存在”的闩锁或自行推断归档。
- [ ] 过期、无权或从未可用的会话目标仍显示不可用，不会被误判为刚归档并自动跳转。
- [ ] 选择另一会话保持现有替换对话目标的行为，重复选择当前会话不无意义重建页面。
- [ ] 归档、恢复和改名后的标题与选择结果在控制台、浮层和标题栏保持一致。
- [ ] 主会话归属、会话归属、通知定位、提醒和后台接收语义保持不变。
- [ ] 会话状态契约测试覆盖归档跟随和异常目标，页面测试覆盖共享浮层的完整用户路径。
