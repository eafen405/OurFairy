## What to build

让用户能够查看和启停本人可见的共有与个人技能，并在首次交互后由 Fairy 通过原生 `skill` 工具按需激活。技能包资源只读可用，同名遮蔽和派生状态清楚可见，每次成功激活都显示 `加载了skill:xxx`。

本票以部署预置的已审核技能完成第一条端到端路径：原生受信装配、个人作用域目录、只读资源、客户端选择与激活提示。后续创建、安装和学习复用这条运行时路径。

## Acceptance criteria

- [ ] 空会话创建时不注入 Skill 目录或正文，首次实际交互才出现当前用户可见的技能概要。
- [ ] 原生文件系统 provider 只使用部署控制的受信 bundled 根；项目、部署用户目录和会话可写目录中的技能不会绕过审核出现。
- [ ] 用户只能看到共有技能与本人的个人技能，管理身份也不能读取其他用户的个人技能。
- [ ] 当前版本的包内资源可以按原生激活指引真实读取，且所有会话都不能改写；历史版本与其他用户的个人版本不可见。
- [ ] 包清单哈希覆盖全部文件，任何内容变化都会使激活完整性检查失败。
- [ ] 每次成功激活产生一条带持久 seq、按工具调用去重的 `加载了skill:xxx` 展示行；目录更新、失败读取、资源读取和 `/name` 文本不产生该行。
- [ ] 激活展示行不进入模型上下文，断线补齐与冷恢复保持正确位置且不重复。
- [ ] 客户端可以逐项启用或禁用技能，共有技能的启停只影响本人。
- [ ] 同名个人与共有技能由后端返回实际赢家及派生状态，包括进入目录、被遮蔽、已禁用和已归档；客户端不自行推导。
- [ ] 发布、启停和同名赢家变化会使受影响在线 Agent 的下一次目录刷新，不需要重启。
- [ ] 真实启动器与 Android 行为测试覆盖上述路径。
