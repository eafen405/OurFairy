# 电费账单文本优化

发布票：[GitHub #341](https://github.com/eafen405/OurFairy/issues/341)。GitHub issue 是发布权威。

## 核心诉求

账单页现在被大段说明文字包围，且总量数字一长就显示不全。用户要的是**只有两个框里的内容**，
数字在三列窄栏里也读得完整。

1. 删去账单界面所有小字，一点不留，只留下两个框中的内容。
2. 超过三位数的数字使用 K、M、B、T 这类单位，保留一位小数。布局不改。

## 范围

- `android/` 的账单页呈现层（`ui/fairy/FairyBillPage.kt`）与其 Robolectric 测试。
- 不动后端聚合、`/bill` 形状、丁尼汇率常量与其余呈现面；不引入新依赖。

## 完成时应看到

- 账单页除两个仪器面板（三个总量、30 天走势）与状态文案外，没有开场说明、汇率说明、口径脚注
  与刷新提示。
- 三个总量的丁尼与 token 在千位以上改用 K/M/B 单位并保留一位小数；千位以下仍是原来的写法。
