## What to build

让会话通知与技能提醒共享通知定位的端点规范化和账号准入，Activity 只执行已接纳的落点，不再内联第二份规则。

## Acceptance criteria

- [ ] 两类通知都经同一通知定位 module 判断端点与账号是否匹配。
- [ ] 会话通知继续执行会话归属检查及打开后的身份二次确认，技能提醒不获得额外权限。
- [ ] 跨端点、跨账号拒绝可在 module interface 上直接测试，无需每种通知都启动完整 Activity。
- [ ] 现有冷启动排队、会话打开与技能页落点测试继续通过。
