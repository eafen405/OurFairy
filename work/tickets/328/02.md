## What to build

把“修订不得同时携带地址安装内容”收进技能创建 domain 契约，使任何生产者都无法构造被记录为安装来源的修订，同时保留工具入口对模型参数形状的校验。

## Acceptance criteria

- [ ] SkillCreation 自身拒绝修订与安装来源的非法组合，不依赖某个 adapter 先检查。
- [ ] 显式创建、安装、后台学习、进化与回滚的来源判定不会互相覆盖。
- [ ] 工具参数校验继续负责模型输入词汇，不大规模搬动其它合法校验。
- [ ] 直接 domain 测试覆盖非法组合，工具创建与后台创建回归测试通过。

## Blocked by

None (can start immediately).
