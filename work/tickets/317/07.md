## What to build

spec 317 的收口：在集成分支的最终状态上跑完整门禁，复核规格里每一条可执行声称都真的有一条会因它失效而失败的检查，并留下证据。

约束：

- 全量 `npm test`、`npm run combo:verify`，涉及 `android/` 时还必须在 `android/` 运行 `./gradlew test lintDebug`。
- 逐条核对规格中「最硬」的声称：前缀逐字节不变的那条测试必须真的会失败，不能是自我声明。
- 证据写在 `work/implementation/evidence/` 下，区分替身测试与真实服务证据。
- 清理实施期遗留的 worktree 与临时分支，交付前 `git status --porcelain` 为空。
