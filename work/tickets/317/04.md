## Parent

#317

## What to build

聊天投影的消息行新增两个字段：该行所属的回合编号，以及该回合结算后的 token 分桶（输入、缓存、输出）。两者都缺省表示该行没有可报告的信息。

约束：

- 回合编号是必需的，不是可选优化：现有行结构与既有索引只对尝试行建了回合索引，普通助手行不带回合，投影无法从既有状态判断某行是不是一个回合的最后一条。
- 分桶只挂在回合的最后一条 Fairy 消息上；中断的回合挂已结算的部分值。
- 不新增行类型，不改变既有的 `position` 语义与稳定性约束。
- 供应商未上报用量时不出现分桶字段。
- 冻结的投影预期不受影响：那些夹具里的助手流不含用量分块，其行没有可报告的用量，新字段在这些行上缺省。这一点是资产，不得为了让实现好写而改动既有夹具。

## Acceptance criteria

- [ ] 投影输出携带回合编号；既有 `position` 语义与稳定性约束不变
- [ ] 回合的分桶只出现在该回合的最后一条 Fairy 消息上
- [ ] 中断的回合给出已结算的部分值，而不是空或全量
- [ ] 供应商未上报用量时该行不带分桶字段
- [ ] 既有冻结投影预期原样通过，且未改动夹具来迁就实现
- [ ] 投影单元状态版本递增，旧缓存按既有规则丢弃并重放
