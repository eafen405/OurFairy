## What to build

Android 后台接收结算整账号积压时，为每个有欠账的落点会话各发一条提醒，点击深链到该会话；不再把所有欠账合并成一条、优先指向主会话。前台不发、关闭后台接收不发布、发布前先消费、等待所有列出会话追平这些规则不变。

## Acceptance criteria

- [ ] 多个会话同时欠提醒时，每个会话各发一条，每条都指向各自的会话 id。
- [ ] 只有主会话欠账时指主会话；只有非主会话欠账时指该会话，不因主会话存在而改指。
- [ ] 点击仍按该会话深链；前台与关闭接收时的抑制不变。
- [ ] 发布前消费、进程重启不重放旧 episode 的语义不变；一个落点的发布失败不影响其他落点。
- [ ] 单会话提醒、预览选择与账本权威的现有测试保持通过；描述「合并成一条」的类注释与积压测试同步更新。
- [ ] 沿用现有 Robolectric / Compose 测试设施，不新增 instrumentation 接缝。

## Blocked by

None (can start immediately).
