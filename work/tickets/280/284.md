## What to build

同一次投递在失败、进程重启后重试时，仍只有一条消息，并且仍在第一次决定的那个会话；即使发起会话在这期间被归档，重试也不改落点。启动时结算未完成投递沿用记录里的落点，因此不新增恢复规则。落点不参与「同身份但内容或收件人不同」的冲突判定。

## Acceptance criteria

- [ ] 首次落点已记录后业务写失败，同一工具调用 id 重试，仍只有一条消息且落在原会话。
- [ ] 首次落点会话在重试前被归档，重试仍落原会话，不改落主会话。
- [ ] 进程重启后，未完成投递在启动时结算到记录里的落点。
- [ ] 同一身份但内容或收件人不同仍被拒绝；落点差异本身不构成冲突。
- [ ] 经真实启动器与现有接缝断言，不新增测试接缝。
