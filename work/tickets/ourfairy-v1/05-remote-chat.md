## Parent

[OurFairy 首版总规格：受邀多用户后端与 Android 客户端](https://github.com/eafen405/OurFairy/issues/23)

## What to build

用户在手机发送文字，由后端 Fairy 运行并流式回复，完成后保存完整正文；用户能停止本轮回复。建立后续功能共同使用的远程会话投影。

涉及仓库：OurFairy、dsh fork、rikkahub fork。

父规格用户故事：4、15、17、23。

依据：[前端最终决议](https://github.com/eafen405/OurFairy/issues/10#issuecomment-6165782525)；[共同接口研究](https://github.com/eafen405/OurFairy/issues/20)；[实施路线最终决议](https://github.com/eafen405/OurFairy/issues/22#issuecomment-6167313227)。

执行交接：遵循父规格的 implement-spec 集成方式，在匹配的独立 worktree 中完成本票；主集成组合记录实际配套提交。测试沿已确认的真实装配/公开接口，结论附实际检查与未执行条件。仅完成本票不表示整个首版或真机验收已经完成。

## Acceptance criteria

- [ ] 显式接入官方 DeepSeek Flash 共用路由及后端凭据；可用外部模型替身完成确定性端到端测试，真实云调用留集成验收，不伪称已验证。
- [ ] 客户端不再直连模型执行该会话；发送身份、稳定请求身份、接纳结果与持久消息对账，重复或未知结果不能静默重复发起。
- [ ] 建立会话/消息/临时 attempt 的稳定身份及公共观察接口，流式原文有序无损累积，正式结束结算为完整消息。
- [ ] 实现基本纯文本流式和结束后的完整格式，停止/错误后保留内容也可收尾；后续性能票完善调度与复杂长文，不能以其未完成为由丢失原文。
- [ ] 停止回复经过归属核对，只取消当前回复；页面退出/观察连接关闭不被当成取消后端工作。
- [ ] 部署人格、主人称呼及外部材料来源按已定规则装配，用户聊天不成为编辑部署设定的入口；不新增输出审查或记忆学习系统。
- [ ] 用真实应用装配验证两用户发送、流式/终态、停止、模型失败及上下文隔离；交付供恢复、工具和呈现票复用的公共会话接口。
