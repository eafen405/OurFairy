## What to build

首页与对话页使用同一份 Fairy 当前表现规则。首页跟随最近选择、缺省回退主会话的当前会话，不再固定显示待机；用户切换会话或账号时，只看到对应当前上下文的真实连接与活动表现。

## Acceptance criteria

- [ ] 首页和对话页由同一 module 生成待机、思考、说话、连接中、离线五种当前表现。
- [ ] 首页只观察当前会话，不汇总账号下所有会话，也不推断 Fairy 的全局 active、wandering、sleeping 状态。
- [ ] 当前会话缺省时回退主会话；切换会话或账号后，旧事实不再驱动页面。
- [ ] 活动未知不会显示成安静；连接与活动事实的语义保持不变。
- [ ] Fairy 当前表现可通过新 module interface 用远程事实替身直接测试，页面测试只补充高层接线验证。
- [ ] 不改变后端协议、会话活动事实、视觉主题或消息呈现行为。
