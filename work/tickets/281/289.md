## What to build

点 PDF 或 docx 时，直接交给手机系统里能打开它的应用，而不是先另存为。交接用 FileProvider 的 content URI，暴露面从「安装包目录」精确扩到附件缓存子目录（不是整个 cache）。系统里没有能打开该类型的应用时，回落到现在的另存为，点了不会没反应。

## Acceptance criteria

- [ ] 点 PDF/docx 拉起系统 chooser，意图带正确 MIME 与临时读授权，接收方拿到的是附件缓存子目录里的文件。
- [ ] FileProvider 只额外暴露附件缓存子目录；安装包目录既有暴露不变；有一条结构测试固定暴露清单，改动 xml 会失败。
- [ ] 没有匹配应用时回落另存为，用户能看到结果，不静默失败。
- [ ] 不需要额外的存储权限，不新增依赖。
- [ ] README/词汇表关于暴露面的描述与 xml 一致。
