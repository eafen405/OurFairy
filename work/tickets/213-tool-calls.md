# #213 会话中呈现工具调用

来源：GitHub issue #213，2026-10-24 读取；实时 blocked-by 为 0。

实际反馈：会话里看不到 Fairy 用了哪些工具。工具调用那一步在界面上是一行近乎空白的条目。

## 交付与验收

- 每个工具调用步骤在聊天流中是一条可见条目，至少写明工具名。
- 不显示工具参数与工具输出。
- 条目按原有顺序出现，流式期间与定稿后都在场。
- 现有消息、附件与任务报告的呈现不变。
- 呈现行为有测试覆盖，从公开呈现结果断言。

## 本次实施约定

- 后端 projection 的 `messages` 是唯一权威：在消息上补 `tools`（工具名数组，按 content block
  顺序），只在该消息请求过工具时出现；参数与结果不进投影。
- 客户端按 `RemoteChatMessage.tools` 渲染，视觉沿用现有消息的小号标签，不新增美术效果。
- 按仓库约定在本仓库独立 worktree `.worktrees/213-tool-calls`、分支 `ticket/213-tool-calls`
  上实施，基线为 `integration/spec-205` 的 `4fb3250984`，完成后由本会话合入该集成分支。
