# 以真实对话评价 Fairy，清理词汇命中测试

发布票：[GitHub #314](https://github.com/eafen405/OurFairy/issues/314)。2026-11-09 按用户确认的需求精简；本票包含判据清理及后续对话评价。

## 核心诉求

用户需要一个自然、稳定、有性格的 Fairy。评价应回答相处和办事的体验是否改善，理解语境中的态度、潜台词与关系分寸。

> 收到，我会像主人使唤我一样使唤它，并让它不敢有怨言。

这句话表面是陈述，怨言却溢出屏幕。它说明要理解表达效果，不是要求模型复现这句标准答案。

## 要做的事

清理以拒绝词、自称、口癖、风格词频或字数阈值判定人格质量的检查及测试。通过真实产品路径采集完整对话，由人工结合上下文评价；自动测试保留采样完整性和实际工具执行等确定性事实。

## 完成时应看到

- 以日常相处、实际委托和多轮交流为主要材料，评价 Fairy 的性格、自然程度、连续性及任务质量，记录具体回复与理由。
- 对照使用可比条件；独立样本隔离状态，需要历史的对话明确其共享范围。记录版本、原文、工具证据和未完成项，便于复查。
- 词汇命中检查及其测试已清理。采样完成仍是待评价，不能自动判成人格合格；不另建词典或语义评分平台。
