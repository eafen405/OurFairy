# 技能

Fairy 可复用工作流及其随附脚本的领域。

## Language

**技能**：
可由 Fairy 在相应情境中复用的工作流，可包含随工作流复用的脚本；不局限于知识说明。

**技能包**：
技能的保存与分发单元，以文件夹承载工作流说明、相关文档和可选脚本。

**技能脚本**：
附属于技能、供 Fairy 复用以避免重复编写的脚本；不是脱离技能独立安装的扩展。

**技能概要**：
供 Fairy 判断技能是否适用的简短信息，包括名称与描述；看到概要不代表已读取完整工作流。

**技能激活**：
Fairy 从当前可用技能中选择一项并读取其完整工作流的运行时行为，不表示审核或启用状态发生变化。

**技能激活提示**：
每次成功激活技能时向用户显示“加载了skill:xxx”的可见提示，其中 xxx 是实际激活的技能名称。

**个人技能**：
归属于一位用户的技能，默认归属产生该技能的用户。

**共有技能**：
面向所有用户的技能，不因某位用户的会话而自动成为共有技能。

**技能候选**：
尚未通过启用审核、不能影响会话行为的技能草稿。

**后台技能候选**：
由至少两个独立会话中重复成功的相似工作流触发自动生成的技能候选；用户显式创建不受此门槛限制。

**技能成功判定**：
独立审查根据用户反馈、工具结果和最终产物，对工作流经历作出成功、失败或无法确定的判定；无法确定的经历不用于自动候选。

**技能复用信号**：
轻量检测认为某段工作流值得进一步挖掘时形成的简短记录，用于达到证据门槛后定位相关材料；它本身不是技能候选。

**技能安装**：
用户向 Fairy 提供技能包地址后，由 Fairy 获取并检查外部技能包、形成技能候选的行为。

**技能启用审核**：
技能候选成为已审核技能前必须通过的审核；自动生成候选不等于批准启用。

**已审核技能**：
已通过启用审核、具备使用资格的技能，可以随后被启用或禁用。

**技能禁用**：
将已审核技能从当前使用范围排除的选择，不等于删除技能或撤销审核。

**已启用技能**：
已审核且在当前使用范围内被选择启用、可供 Fairy 使用的技能。

**技能选择池**：
客户端允许当前用户逐项启用或禁用的已审核技能集合，只包含共有技能与本人的个人技能。

**共有技能启用偏好**：
当前用户对共有技能的个人启用或禁用选择，只影响本人；共有内容的全局有效性由法厄同另行管理。

**同名遮蔽**：
本人的个人技能与共有技能同名时，只有个人版本进入本人的模型目录；选择池仍呈现两项及其归属，禁用个人版本后共有版本可重新进入目录。

**技能进化**：
对现有技能进行整体重写并形成新当前版本的行为；新当前版本是独立完整、简洁自洽的工作流。

**技能历史版本**：
与当前版本分离、仅用于审计和回滚的旧版本，不参与技能目录与激活。

**技能修订候选**：
技能进化产生的新版本候选；审核期间原当前版本继续可用，审核通过后新版本成为唯一当前版本。

**技能篇幅异常增长**：
新当前版本的核心工作流正文较原版本增长超过百分之十；除常规候选审核外，审核人还必须显式确认这次增长。

**技能增长确认**：
审核人在看到新旧正文长度与增长比例后，通过独立用户回合明确接受技能篇幅异常增长的动作；模型不能代替审核人确认。

**技能派生状态**：
后端根据审核、启用偏好、归档和同名遮蔽计算出的技能呈现状态，说明技能实际进入目录、被遮蔽、禁用、归档或存在待审修订。

**技能创建认领**：
针对同一所有者的同类技能复用信号形成的唯一深度创建任务，独立于各源会话的检测水位恢复与重试。

**技能归档**：
使技能退出选择池并保留内容、来源与审核历史的可恢复动作；个人技能由所有者归档，共有技能由法厄同归档。
