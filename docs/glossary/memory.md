# 记忆

Fairy 跨会话保留并使用认识的领域。

## Language

**印象**：
每位用户一份，包含 Fairy 对这位用户形成的、每次互动都需要知道的持续整体认识，在该用户的对话中无需检索即可使用。用户只能查看本人的印象；Fairy 可在用户明确要求时修改，不随时间流逝自动失效。印象描述用户，不承载对 Fairy 自身人格或行为的要求。
_客户端：_提供本人印象的只读查看，不提供长期记忆条目管理页。

**印象编辑**：
Fairy 根据用户明确要求对印象进行的有意识修改，不随记忆维护自动发生；修改前必须先读取当前印象。

**长期记忆**：
Fairy 跨会话保留、只在相关情境下需要回忆的具体事实或经历。

**普通记忆**：
长期记忆的默认层级，可由普通检索命中。

**私密记忆**：
经显式层级切换转变的长期记忆，只能由深层检索命中。

**普通检索**：
只面向普通记忆的记忆检索。

**深层检索**：
只面向私密记忆的记忆检索。

**记忆层级切换**：
将一条记忆在普通与私密之间显式转换的动作，不产生第二份记忆。

**记忆编号**：
与一条记忆一一对应的整数标识，编辑不改变，删除后不复用。

**内容更新时间**：
记忆最近一次新增或编辑内容的时间，日期检索以此为依据；查询与层级切换不改变它。

**记忆失效**：
一条记忆不再适合作为 Fairy 当前认识的状态；失效后即物理删除该记忆。

**记忆来源**：
记忆所依据的会话，来源用户由该会话的归属确定。

**维护区间**：
一次记忆维护处理的源会话范围，以开始维护为封口；维护子会话与源会话并行，此后的响应进入下一区间。

**维护材料**：
维护区间内的用户消息、Fairy 回复、附件名称和记忆变更调用。

**维护触发回合数**：
待维护区间的初始长度设置，以闭合用户回合计，默认为 15，可调范围为 5–50。

**维护门槛衰减间隔**：
当前维护门槛随区间最新闭合消息闲置而减 1 的时间间隔，默认为 6 小时，可调范围为 3–24 小时。

**当前维护门槛**：
由维护触发回合数随维护门槛衰减间隔逐次减 1 得到的运行时长度，最低为 1 个闭合用户回合。

**记忆维护**：
以单个会话为单位，根据维护材料与已有记忆，写入、更新或删除记忆的增量过程，在维护材料达到当前维护门槛且该会话处于静默会话状态时开始；维护子会话只能使用记忆工具，并通过普通检索与深层检索查找相关旧记忆。
