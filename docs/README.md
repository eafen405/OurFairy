# OurFairy 文档导航

本页导航 `docs/` 下的目录，不复述各目录内文件的内容。仓库拓扑与版本来源的唯一权威在根 [README](../README.md)。

| 目录 | 一句话定位 | 档位 |
| --- | --- | --- |
| [`specs/`](specs/) | 需求与约束的权威 | 现行 |
| [`architecture/`](architecture/) | 模块边界与未采用的原生接缝 | 现行 |
| [`adr/`](adr/) | 难逆的取舍 | 现行 |
| [`agents/`](agents/) | 给代理的流程规则 | 现行 |
| [`glossary/`](glossary/) | 局部上下文的领域词汇：外部感官与记忆 | 现行 |
| [`decisions/`](decisions/) | 日期化决策记录 | 日期化 |
| [`research/`](research/) | 日期化调查 | 日期化 |
| [`archive/`](archive/) | 已归档的提案与讨论 | 历史 |

「现行」描述当前状态，必须今天为真；「日期化」记录某个日期的判断，正文保留原貌；「历史」已归档，不再更新。

档位按目录归属：本索引给的是目录档位，也是该目录下文件的缺省。文件没有状态头时，按所在目录的档位读；
带状态头的文件以状态头为准，文件级状态头覆盖所在目录的档位。目录档位是缺省、文件状态头是显式声明，两者不冲突。

`docs/` 之外的词汇入口见根 [`GLOSSARY-MAP.md`](../GLOSSARY-MAP.md)：它把产品全局（`GLOSSARY.md`）、
客户端（`android/GLOSSARY.md`）与 `docs/glossary/` 下的外部感官、记忆连成一张图。术语按所在上下文读，
不要只读 `glossary/`。
